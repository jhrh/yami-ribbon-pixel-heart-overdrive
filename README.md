# Yami Ribbon: Pixel Heart Overdrive

Prototipo arcade 2D HTML5 de Yami Ribbon. No requiere dependencias ni compilador externo: el juego se ejecuta directamente en el navegador.

## Jugar localmente
Abre `index.html` en un navegador moderno. También puedes servir la carpeta con cualquier servidor estático.

## Controles
- Mover: A/D o flechas izquierda/derecha
- Saltar: Espacio o flecha arriba
- Atacar: Z o J
- Cambiar integrante: 1, 2, 3 (o botón ↻ en móvil)
- En pantalla táctil aparecen controles virtuales.

## Publicación automática
Cada push a `main` ejecuta GitHub Actions y publica el sitio en GitHub Pages. También puedes iniciar el workflow manualmente desde Actions.
